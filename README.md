# Sudhanshu — Portfolio Prototype

A visual prototype (not an implementation) of a personal portfolio site for a
PHP / Laravel backend engineer.

## Direction

Light editorial: warm off-white paper, deep warm ink, a single clay accent,
generous whitespace and an asymmetric editorial grid.

| Role | Face | Fallback |
| --- | --- | --- |
| Display | Instrument Serif | Georgia, Times New Roman, serif |
| Body / UI | Schibsted Grotesk | Helvetica Neue, Arial, sans-serif |
| Labels / meta | JetBrains Mono | ui-monospace, SF Mono, Menlo |

Palette: paper `#FBF9F5`, band `#F6F2EB`, ink `#16130F`, body `#4A443C`,
muted `#8A8177`, rule `#E2DCD2`, accent `#C0502C`.

## Placeholders

Anything in `[square brackets]` is a placeholder waiting on real details:
name, companies, dates, city, email, photo, screenshots and metrics. The
project write-ups are drafted examples for a backend role, not real work.
